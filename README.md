# Garage PWA

Garage es una aplicación web progresiva (PWA) pensada para organizar y administrar información de vehículos desde un solo lugar. Permite llevar un registro de los vehículos personales, controlar mantenimientos, consultar gastos y registrar información útil sobre cada unidad.

El proyecto se desarrolla por versiones, incorporando mejoras de diseño, navegación y funcionalidades a medida que avanza.

## Características

- Gestión de vehículos personales.
- Registro de mantenimientos y servicios.
- Control de gastos relacionados con los vehículos.
- Seguimiento de consumo de combustible.
- Interfaz adaptable a dispositivos móviles y computadoras.
- Instalación como aplicación mediante tecnologías PWA.
- Acceso a determinadas funciones sin conexión, mediante Service Worker y caché.

*Las funcionalidades disponibles pueden variar según la versión.*

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Web App Manifest
- Service Worker
- LocalStorage

## Cómo ejecutar el proyecto localmente

1. Clonar o descargar este repositorio.
2. Abrir la carpeta de la versión que se quiera probar.
3. Abrir el proyecto con Visual Studio Code.
4. Ejecutar `index.html` mediante la extensión Live Server.

Se recomienda utilizar un servidor local para probar correctamente las funciones PWA y el Service Worker.

## Objetivo del proyecto

Garage nace como un proyecto de desarrollo web orientado a centralizar la información y el seguimiento de vehículos personales.

Su desarrollo también forma parte de un proceso de aprendizaje en diseño y programación web, aplicando progresivamente conceptos de HTML, CSS, JavaScript, Bootstrap y tecnologías PWA.
