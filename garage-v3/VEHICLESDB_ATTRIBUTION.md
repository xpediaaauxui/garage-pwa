# Atribución de datos de vehículos

GARAGE utiliza y adapta datos del proyecto **VehiclesDB: Open vehicle data**, publicado por VehiclesDB.

- Fuente: https://github.com/vehiclesdb/vehiclesdb
- Archivo consultado: `dist/vehicles.json`
- Versión integrada: `2026.11.10`
- Licencia de los datos abiertos: Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/
- Adaptación realizada por GARAGE: se filtran las categorías `car` y `van`, se ordenan marcas y modelos para los formularios y se añade una opción local para registros no catalogados.

VehiclesDB y las marcas mencionadas conservan sus respectivos derechos. GARAGE no está afiliado ni respaldado por los fabricantes.
